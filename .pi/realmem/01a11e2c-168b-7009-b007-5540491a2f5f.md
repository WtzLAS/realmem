`/realmem consolidate [global|shared|personal] [--no-paths]` (extensions/realmem/index.ts `consolidate()`) calls `Realmem.planConsolidation(opts)`, which writes nothing, then `applyConsolidation(cwd, plan)`. The pure parts live in `src/consolidate.ts`: `buildReviewRequest`/`readReview`/`decideReview` (SemIf questions covered_by/conflict_with/merge_with/forget/importance/revise; decision order forget > covered > supersede > merge > revise > keep), `renderTree`, `buildSummaryPrompt`/`buildPathsPrompt`/`parsePathsAnswer`, `formatPlan`/`planSummary`. Memories are reviewed least used first, against neighbours from the same store only. The repo summary is cached in the `meta` table under `consolidate-summary:<root>`, keyed by the sha256 of the tree. Settings are under `settings.consolidate` (forget, minImportance, revise, neighbors, paths, pathBatch, treeLines). `rewriterFor()` in tools.ts also returns a `completer` (`createCompleter` in src/rewrite.ts) for plain model calls. `safeRewrite()` in engine.ts is the shared model→fallback+safety-scan helper; RewriteRequest has mode `revise` (no candidate). Tests: tests/consolidate.test.ts. Hand-written test memory files need quoted captions when they contain `: `.
