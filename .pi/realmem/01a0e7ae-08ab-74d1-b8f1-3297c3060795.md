`DEFAULT_SETTINGS.embedding.model` and `.semif.model` are `""` (no hardcoded names). `EmbeddingClient`/`SemIfClient` (src/api.ts) have `listModels()` (via `parseModelIds`, accepts `{data:[{id}]}`, `{models:[...]}`, arrays) and `model()`: configured name, else the server's only listed model (cached per client instance), else ApiError "pick one in /realmem settings". Settings page uses field kind `remote-model` + `RemotePicker` (extensions/realmem/ui.ts) which fetches /v1/models with the *draft* settings; extras `(auto)` and "✎ type a name…". `semif.maxQuestions` cap is 255; `candidates.max` stays 254 (254 ids + `none` = SemIf's 255-option choice limit). Embedding fingerprint uses the configured string, so `(auto)` doesn't include the resolved name.
