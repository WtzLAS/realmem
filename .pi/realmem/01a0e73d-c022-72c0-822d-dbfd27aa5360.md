`urgency` table (src/db.ts) has `probs` (JSON, keys "0".."2" = Low/Mid/High) and `confidence` columns since SCHEMA_VERSION 3; `setUrgency(..., { probabilities, confidence })`. Decision carries `urgencyProbs`/`urgencyConfidence`. Shared TUI rendering lives in `extensions/realmem/urgency-view.ts` (`urgencySummary`, `urgencyBreakdown`), used by manage-page.ts (detail section + one-char list column ● full ◐ caption ○ count ? unjudged) and debug-page.ts ("Path urgency" section; `p` key sets candidate paths, needed because urgency is only asked when the candidate has paths). TUI tests use WIDTH 72, so list descriptions and long hints get truncated; assert on label columns.
