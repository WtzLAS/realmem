The `pending` table (src/db.ts) stores `project_root` (NULL = queued outside any project). `listPending(root)` and `countPending(root)` match `project_root IS ?` exactly — no NULL fallback — so the footer `(+N queued)`, `status().pending`, `drain()` and `/realmem retry` only see the current project's queue. Use `Realmem.pendingCount(cwd)` from extension code. Test: "queued candidates are local to their project" in tests/engine.test.ts.
