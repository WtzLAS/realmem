`/realmem consolidate` (extensions/realmem/index.ts `consolidate()`) is fully automatic: no confirmation dialog, no plan review, no per-step approval (an interactive per-step version, commit 7941c25, was rejected and reverted). Inside a single `runWithLoader` it calls `e.planConsolidation(...)`, then `e.applyConsolidation(ctx.cwd, plan)` if `plan.ops` is non-empty; nothing is written before planning finishes, and `esc` cancels while it runs. Afterwards one notify shows the counts plus `formatPlan(plan)` lines, with level warning if `plan.warnings` is non-empty. A `rewriterFor` error is shown upfront as a warning notify. The README "Consolidation" section describes this flow. Pure logic stays in `src/consolidate.ts`: `buildReviewRequest`/`readReview`/`decideReview` (SemIf questions covered_by/conflict_with/merge_with/forget/importance/revise; decision order forget > covered > supersede > merge > revise > keep), `renderTree`, `buildSummaryPrompt`/`buildPathsPrompt`/`parsePathsAnswer`, `formatPlan`/`planSummary`. Memories are reviewed least used first, against neighbours from the same store only. The repo summary is cached in the `meta` table under `consolidate-summary:<root>`, keyed by the sha256 of the tree. Settings under `settings.consolidate` (forget, minImportance, revise, neighbors, paths, pathBatch, treeLines). `rewriterFor()` in tools.ts also returns a `completer` (`createCompleter` in src/rewrite.ts) for plain model calls. `safeRewrite()` in engine.ts is the shared model→fallback+safety-scan helper; RewriteRequest has mode `revise` (no candidate). Tests: tests/consolidate.test.ts. Hand-written test memory files need quoted captions when they contain `: `.
