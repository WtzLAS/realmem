`/realmem consolidate` (extensions/realmem/index.ts `consolidate()`) calls `runConsolidate()` in `extensions/realmem/consolidate-page.ts`, which runs `Realmem.consolidate({ ...opts, approve, onWritten })` (src/engine.ts). No upfront confirm, no whole-plan review. Each forget / fold / revise / paths step becomes a `ConsolidationProposal` (src/consolidate.ts: `op`, `before` MemoryView[] (reviewed memory, then fold target), `after`, `progress` like "review 3/42" / "paths 2/10"), rendered by `formatProposal()`. TUI: `ConsolidateScreen` swaps CancellableLoader and TextView; y = accept, n = skip, q/esc = stop. Non-TUI: `ctx.ui.select`; with no UI every step is auto-accepted. An accepted step is written immediately via private `writeConsolidation(ctx, {ops, changed, deleted})` under WRITE_LOCK, then live state reloads from the DB. `planConsolidation`/`applyConsolidation` still exist: both use the shared private `runConsolidation(opts, interactive?, tally)`; tests use them. `afterConsolidation(cwd)` runs background embed, urgency and path checks. Pure logic in `src/consolidate.ts`: `buildReviewRequest`/`readReview`/`decideReview` (SemIf questions covered_by/conflict_with/merge_with/forget/importance/revise; decision order forget > covered > supersede > merge > revise > keep), `renderTree`, `buildSummaryPrompt`/`buildPathsPrompt`/`parsePathsAnswer`, `formatPlan`/`planSummary`. Memories are reviewed least used first, against neighbours from the same store only. Repo summary cached in `meta` table under `consolidate-summary:<root>`, keyed by sha256 of the tree. Settings under `settings.consolidate` (forget, minImportance, revise, neighbors, paths, pathBatch, treeLines). `rewriterFor()` in tools.ts also returns a `completer` (`createCompleter` in src/rewrite.ts) for plain model calls. `safeRewrite()` in engine.ts is the shared model→fallback+safety-scan helper; RewriteRequest has mode `revise` (no candidate). Tests: tests/consolidate.test.ts ("interactive consolidate …") and tests/tui.test.ts ("consolidate page …"); TUI test's review count includes global memories left by earlier tests, so assert `/review 1\/\d+/`.
